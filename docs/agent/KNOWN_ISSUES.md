- **P2.1 BFLA remaining (low):** The privileged-function classifier is a built-in path/method heuristic, not policy-driven. Plain destructive-on-object routes (`DELETE /users/{id}`, `DELETE /tenants/{id}`, `/organizations/{id}/members/{id}`) are **not** flagged as BFLA — distinguishing an admin deleting another user from a user deleting their own account needs ownership context (BOLA's domain). Deferred to a future slice rather than risk false positives on self-service deletes. Role is read from JWT claims (`role`/`roles`/`is_admin`) or the empty-hierarchy name heuristic (`admin|root|superuser`); privileged role *names* outside that set (e.g. `owner`, `manager`) are only recognized when declared in the policy role hierarchy.
- **P2.2 CSRF remaining (low):** Never Confirmed from a passive capture (needs a cross-site forge in a browser). A no-SameSite-attribute cookie is reported at Observation (modern Lax default blocks cross-site POST; legacy browsers do not). `X-Requested-With` is intentionally not treated as protection, so jQuery/Angular apps that rely on it will surface Observation/Suspicion candidates to verify.
- **P2.3 refresh remaining (low):** Always Suspicion — a short reuse/leeway window is RFC 9700-legitimate, so passive capture cannot confirm broken rotation. Detection is scoped to token/refresh endpoints; a refresh flow on an unrecognized path (no `grant_type`, no token-endpoint-shaped URL) is not analyzed.
- **P2.4 spec remaining (low):** JSON only (YAML refused with a message). Host filtering needs the spec to declare `servers`/`host`; a spec with no declared host cannot filter third-party traffic out of the shadow list. `$ref`-composed path items are not resolved.
